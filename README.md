# \# RPG Character Editor

# 

# \## Описание проекта

# 

# RPG Character Editor — это консольное приложение на языке C#, позволяющее редактировать RPG-персонажа и сохранять историю его изменений.

# 

# Пользователь может изменять параметры персонажа:

# 

# \* имя;

# \* класс;

# \* оружие;

# \* броню;

# \* уровень;

# \* количество золота.

# 

# После каждого изменения программа сохраняет состояние персонажа. Пользователь может отменить последнее действие с помощью механизма Undo.

# 

# \---

# 

# \## Постановка задачи

# 

# Разработать консольное приложение для редактирования RPG-персонажа с возможностью сохранения и восстановления предыдущих состояний объекта.

# 

# Программа должна:

# 

# \* хранить информацию о персонаже;

# \* позволять изменять характеристики;

# \* сохранять историю изменений;

# \* реализовывать откат к предыдущему состоянию.

# 

# \---

# 

# \## Используемый паттерн

# 

# В проекте используется паттерн проектирования \*\*Memento\*\*.

# 

# \### Назначение паттерна

# 

# Паттерн Memento позволяет сохранять внутреннее состояние объекта без нарушения инкапсуляции и восстанавливать его позже.

# 

# \### Как используется в проекте

# 

# В приложении состояние персонажа сохраняется перед каждым изменением.

# 

# Если пользователь выбирает команду Undo, программа восстанавливает предыдущее состояние персонажа.

# 

# \### Структура паттерна

# 

# \* `Character` — Originator

# \* `CharacterMemento` — Memento

# \* `History` — Caretaker

# 

# \---

# 

# \## Функционал приложения

# 

# Программа поддерживает следующие возможности:

# 

# 1\. Просмотр информации о персонаже

# 2\. Изменение имени

# 3\. Изменение класса

# 4\. Изменение оружия

# 5\. Изменение брони

# 6\. Повышение уровня

# 7\. Добавление золота

# 8\. Undo последнего изменения

# 

# \---

# 

# \## Пример работы программы

# 

# \### Исходное состояние

# 

# ```text

# Name: Arthur

# Class: Warrior

# Weapon: Sword

# Gold: 100

# ```

# 

# \### После изменений

# 

# ```text

# Weapon changed to Bow

# Class changed to Archer

# ```

# 

# \### После Undo

# 

# ```text

# Class restored to Warrior

# ```
